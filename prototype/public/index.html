Set up sharing

iPhone: Instagram → Share to… → Shortcut
  1. Open Shortcuts, tap +, add the action Get Contents of URL.
  2. URL:
  3. Tap Show More: Method POST, Request Body JSON.
  4. Add field url → value Shortcut Input. Add field token → .
  5. Optional: add Show Notification “Saved to your brain”.
  6. Tap ⓘ, turn on Show in Share Sheet, accept URLs and Text. Name it “Save to Brain”.
  7. In Instagram open a reel → Share → Share to… (or More) → Save to Brain.

Android: install this app → appears in Share menu
  1. Open this page over HTTPS (run npx ngrok http 3000 and use its https URL). Chrome only installs web apps from HTTPS.
  2. Chrome menu ⋮ → Install app (or Add to Home screen).
  3. Set your token above once (it's saved as a cookie for shares).
  4. In Instagram open a reel → Share → Share via… (or More) → Brain.
Anywhere: copy link + paste
  1. In Instagram tap Share → Copy link.
  2. Open this page and tap Paste from clipboard (needs HTTPS or localhost) or paste into the box.
